    FROM LOCAL LAB TO LASNA

    Ready for
    the next block.

    The ZIP includes the complete source and a deployment runbook. This dashboard never sends public-chain transactions.

    1. Connect your testnet accounts

      Copy .env.example to .env. Use dedicated funded Base Sepolia and Lasna accounts. Set a separate reporter address and key.

    2. Verify and deploy

      npm run preflight
      npm run deploy:testnet

      Network IDs and documented Omni system addresses are checked before deployment.

    3. Start the live worker

      npm run worker

      It waits for authenticated assessment jobs, verifies the listing commitment, runs the model, and commits the report.

    4. Run a trade and collect proof

      node scripts/open-escrow.mjs risky SELLER_ADDRESS
      npm run evidence -- ESCROW_ID

      Collect the actual origin, Reactive, and callback hashes. Confirm a low-risk release and high-risk refund.

    5. Make the submission yours

      Register on DoraHacks, confirm eligibility and deadline timezone, publish your repository, and record a demo under three minutes. See docs/SUBMISSION.md.
